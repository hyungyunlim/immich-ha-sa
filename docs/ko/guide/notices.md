# 가족 공지

공지는 *🍽️ 오늘 저녁 7시 외식* 같은 짧은 문구입니다. 액자가 슬라이드쇼 아래쪽에 작은 알약 모양으로 띄웁니다. 공지가 여러 개면 8초마다 하나씩 번갈아 보여줍니다.

## Frames 패널에서

Home Assistant 사이드바의 **Frames**를 열고 **공지** 탭을 고릅니다.

1. 공지 내용을 입력합니다(140자까지, 이모지 가능).
2. **모든 액자** 또는 액자 하나를 고르고, 보여줄 기간을 고릅니다: 오늘 밤까지, 내일 밤까지, 1시간, 1주일, 지울 때까지.
3. **액자에 띄우기**를 누르면 1초 안에 액자에 나타납니다.

입력란 아래 목록에서 지금 띄운 공지와 대상 액자, 표시 기간을 볼 수 있습니다. **삭제**를 누르면 액자에서 바로 사라지고, 기간이 지난 공지는 저절로 사라집니다.

공지는 컨트롤러가 띄우는 모든 액자에서 동작하며 보조 앱이 필요 없습니다. 화면이 꺼져 있는 동안에는 보이지 않습니다.

## 자동화에서

`immich_frame.show_notice`로 자동화나 스크립트에서 공지를 띄울 수 있습니다.

```yaml
action: immich_frame.show_notice
data:
  message: "🧺 세탁이 끝났어요"
  duration: 60        # 분 단위, 빼면 지울 때까지 표시
  device_id: kitchen  # 컨트롤러 디바이스 ID, 빼면 모든 액자
```

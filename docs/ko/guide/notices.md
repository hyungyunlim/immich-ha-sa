# 가족 공지와 일정

공지는 *🍽️ 오늘 저녁 7시 외식* 같은 짧은 문구입니다. 액자가 슬라이드쇼 아래쪽에 작은 알약 모양으로 띄웁니다. 공지가 여러 개면 8초마다 하나씩 번갈아 보여줍니다.

## Frames 패널에서

Home Assistant 사이드바의 **Frames**를 열고 **공지** 탭을 고릅니다.

1. 공지 내용을 입력합니다(140자까지, 이모지 가능).
2. **모든 액자** 또는 액자 하나를 고르고, 보여줄 기간을 고릅니다: 오늘 밤까지, 내일 밤까지, 1시간, 1주일, 지울 때까지.
3. **액자에 띄우기**를 누르면 1초 안에 액자에 나타납니다.

입력란 아래 목록에서 지금 띄운 공지와 대상 액자, 표시 기간을 볼 수 있습니다. **삭제**를 누르면 액자에서 바로 사라지고, 기간이 지난 공지는 저절로 사라집니다.

공지는 컨트롤러가 띄우는 모든 액자에서 동작하며 보조 앱이 필요 없습니다. 화면이 꺼져 있는 동안에는 보이지 않습니다.

## 캘린더 일정

**Frames** 패널의 **일정** 탭에서 고른 Home Assistant 캘린더의 다가오는 일정을 공지 사이에 *[오늘] 19:00 도윤 수영*, *[내일] 종일 할머니 생신*처럼 보여줍니다.

1. 보여줄 캘린더를 고릅니다. 구글 캘린더 통합, Remote Calendar(iCal 링크), 로컬 캘린더 등 Home Assistant 캘린더라면 모두 됩니다.
2. 일정을 띄울 액자와 기간(오늘만, 3일, 1주일)을 고릅니다.
3. **저장**을 누르면 아래 목록에 액자에 표시될 일정이 나옵니다.

### 달력 위젯

**달력 위젯으로 보기**를 켜면 알약 대신 액자 아래쪽에 카드가 하나 뜹니다. 작고 차분한 카드로, 왼쪽에는 오늘 날짜에 동그라미를 친 이번 달 달력(일정 있는 날은 점 표시), 오른쪽에는 *오늘의 일정* 목록으로 공지와 다가오는 일정이 나옵니다(오늘 일정은 시간만, 이후 일정은 날짜도 함께). 캘린더를 하나도 고르지 않아도 이번 달 달력과 공지를 보여주는 위젯으로 쓸 수 있습니다. 끄면 다시 알약으로 돌아갑니다.

통합구성요소는 15분마다, 그리고 저장할 때마다 캘린더를 다시 읽습니다. 액자는 공지 다음에 아직 끝나지 않은 일정 다섯 개를 보여주고, 오늘 일정은 주황색으로 표시합니다. 같은 캘린더를 두 계정에서 구독해도 일정은 한 번만 나옵니다.

## 자동화에서

`immich_frame.show_notice`로 자동화나 스크립트에서 공지를 띄울 수 있습니다.

```yaml
action: immich_frame.show_notice
data:
  message: "🧺 세탁이 끝났어요"
  duration: 60        # 분 단위, 빼면 지울 때까지 표시
  device_id: kitchen  # 컨트롤러 디바이스 ID, 빼면 모든 액자
```
